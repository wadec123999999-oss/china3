# 北京人工审核数字路书放行清单 V0.1

## 可交付前，审核者必须逐项确认

1. 客户的旅行日期、满天数、抵达/离开机场与时刻。
2. 故宫、天安门区域、天坛、颐和园等当日官方预约和实名规则（只确认客户自行操作的官方入口）。
3. 长城段、天气、转场、末班/返回风险、体力和恐高适配。
4. 798 当期展览、收费、语言可用性与闭馆情况。
5. 客户的支付、数据连接和地图使用准备。
6. 每天不超过两个高摩擦锚点；必须有雨天或疲劳替代。
7. 所有胡同建议均不包含私人空间、居民拍摄或“真实性”承诺。
8. 文案不含代订、打包、报价、接送、导游或体验销售承诺。

## 放行状态

| 状态 | 意义 | 可否交付 |
|---|---|---|
| draft | 仅由数据库生成 | 否 |
| human_checked | 动态信息已按客户日期复核 | 可作为数字路书交付 |
| field_verified | 现场流程也已完成记录 | 可提升为稳定首发模板 |
| commercial_partner_ready | 另有合规、合同与供应商放行证据 | 本数据库不能自行赋予该状态 |

## 红线

任何一项预约、天气、交通或入场规则无法复核时，删去确定性行程，改为“待客户自行确认官方渠道后的备用块”。
