# 苏州人工审核数字路书放行清单 V0.1

1. 确认上海当天往返或苏州过夜；当天往返只可一座主园林＋一段城中水路。
2. 按客户日期复核园林、博物馆、虎丘、演出和夜游的预约、开放、天气与实际步行。
3. 确定园林主诉求，选择一座主园林；不把多园当完成度。
4. 同里／周庄需额外完整一天、当前交通与人群判断，不能替代苏州主城。
5. 昆曲、评弹、刺绣、丝绸等只在当前节目、语言、合规和供应商证据齐备时才进入体验层。
6. 城市水路仅使用公共空间，写明居民、私宅、礼仪与摄影边界。
7. 杭州和苏州按客户真实意图选一座或分配足够夜数，不默认两地全做。
8. 不包含代订、接送、导游、打包门票住宿、第三方体验报价或可进入保证。
