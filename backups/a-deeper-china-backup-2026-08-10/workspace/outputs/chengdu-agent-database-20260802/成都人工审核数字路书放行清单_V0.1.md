# 成都人工审核数字路书放行清单 V0.1

## 客户交付前

1. 核对抵达时刻、满天数、数据与支付准备。
2. 按客户日期复核熊猫基地的官方实名预约、护照匹配、入口与天气。
3. 确认客人是否真想看熊猫；若否，走“无熊猫成都”而非劝说。
4. 核对辣度、过敏、饮食、拼锅和排队容忍度；不承诺具体餐厅。
5. 核对茶馆/演出/798式当代空间等任何当前项目的营业、票务、语言与返程。
6. 都江堰、青城山须单独核验全天交通、天气、体力和回程。
7. 成都—重庆只提供节奏衔接和各自路书，不打包、不代订。
8. 文案不含票价、班次、动物活跃度、体验报价或可进入保证，除非当日人工复核后写入。

## 放行

| 状态 | 含义 |
|---|---|
| draft | 数据库草稿，不能向客户作运营性承诺 |
| human_checked | 按客户日期完成动态复核，可交付数字路书 |
| field_verified | 有现场运行记录，可作为稳定模板 |
| partner_ready | 需另行完成合规、合同与供应商证据；本底库不能自行授予 |
