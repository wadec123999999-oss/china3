# 景德镇故事卡与输出禁区 V0.1

## 产品句

Jingdezhen is a living industrial-artistic ecology. Porcelain is not an object first; it is material knowledge, heat, labour, standards, design, trade and contemporary artistic risk.

## 核心规则

- 两天只交付公共遗产、技术史和当代观察；不默认工坊。
- 私人工作室是工作空间，必须有独立同意与体验放行。
- 一次体验、课程、职业训练、驻留、学徒制不是同一个产品。
- 烧成、破损、寄送、海关与版权是独立风险，不在路书中承诺。
- 市场和陶溪川可用于观察当代生态，不用于鉴定品质、艺术价值或价格。

## 输出禁区

- 不保证艺术家、工作室、窑、课程、驻留、展览、烧成或作品交付。
- 不鉴定、不代购、不定价、不寄送、不保证出口或食品安全。
- 不拍摄工艺过程、劳动者、作品或私人空间，除非获得明确同意。
- 不将学徒制、驻留签证或职业培训包装成旅行体验。
