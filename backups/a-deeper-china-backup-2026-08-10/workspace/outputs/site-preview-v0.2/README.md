# A Deeper China — website preview V0.2

This is a separate, non-deployed static preview. It does not modify the existing
Next.js site or the V0.1 preview.

## Design direction

- Swiss/editorial structure with a restrained warm-paper palette.
- One signature move: a real itinerary shown as a before/after editorial audit.
- One primary conversion: `Check my itinerary`.
- Prices, turnaround and the no-bookings boundary are visible above the fold.
- No fake AI dashboard, no expert marketplace, no gradients, no decorative metrics.
