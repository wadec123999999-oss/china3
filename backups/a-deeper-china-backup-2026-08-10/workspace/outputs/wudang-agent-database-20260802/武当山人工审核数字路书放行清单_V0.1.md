# 武当山人工审核数字路书放行清单 V0.1

此清单服务于“人工复核数字路书”，不是旅行团、票务、交通、住宿或课程预订流程。每份客户路书单独留档；任一红线未通过，即降级为研究型行前建议，不可标为 **Human-checked**。

## A. 客户适配（路书编辑前）

- [ ] 客户的实际抵达/离开、可用夜数、下一站和天气弹性已确认。
- [ ] 客户主目标已选定：遗产建筑、山地步行、道教历史、摄影，或经放行的初级太极体验。
- [ ] 已询问台阶、步行、儿童、伤病和行动限制；涉及心肺、怀孕、严重伤病、行动障碍时转人工，不作适宜性判断。
- [ ] 已明确客户接受“同日官方信息优先”，不会把索道、开放区域、日出或天气当承诺。
- [ ] 客户知晓：所有票务、交通、住宿和任何体验均自行向官方或供应方预订。

## C. 路线质量门槛

- [ ] 2 晚以内只保留一条核心叙事，不叠加偏远点、长距离往返和太极课。
- [ ] 主路线写明强度与“何时撤回”；备选路线不是把同样行程压缩到雨天。
- [ ] 每个动态环节均标为“交付后仍需以官方/现场为准”。
- [ ] 写明寺观礼仪、拍摄须征得许可、非公开区域不得尝试进入。
- [ ] 不使用“正宗、神秘、疗愈、治疗、保证、名师、包见、包上山、包出片”等销售语言。
- [ ] 未通过资源审核的太极/武术机构只可作为“用户自行研究方向”，不可出现名称、价格、联系方式、预订引导或推荐排序。

- [ ] 可公开的授课者姓名、教学经历/资历、实际授课者与宣传一致；不把口碑当师承证明。
- [ ] 英语授课能力有现场或书面证据；如需翻译，明确翻译人、费用、责任和可用时段。

## E. 交付留痕与退出条件

- [ ] 留存来源链接、截图/日期、复核结论与未解决风险。
- [ ] 交付页首标注“独立旅行信息与人工复核；非导游、非医疗、非宗教服务、非预订代理”。
- [ ] 遇极端天气、运营变化、身体不适、语言无法保障或资源证据失效时，主动停止具体推荐，改给取消/改期/官方求助路径。
