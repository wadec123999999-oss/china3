# 上海现场核验与放行计划 V1.0

数据库和英文路书可以先作为人工审核草稿使用；只有下面六项获得真实证据后，才可升级为现场验证或收费产品。

| 编号 | 核验对象 | 最低证据 | 放行决策 |
|---|---|---|---|
| SHRUN001 | 人民广场—上海博物馆/周边 | 入口、英语信息、安检/寄存、实际耗时、厕所与雨天照片/记录 | 决定首访和亲子雨天路书是否可交付 |
| SHRUN002 | 外滩—过江—浦东 | 实际过江方式、等待、人流、蓝调/雨天、返程与安全退出 | 决定城市总览线是否可交付 |
| SHRUN003 | 衡复—武康—公园 | 连续步行、树荫/厕所、住区隐私边界、施工/拥挤记录 | 决定建筑慢行线是否可交付 |
| SHRUN004 | 杨浦滨江或西岸 | 起终点、连续性、休息点、节目/开放、晚间照明 | 决定二访城市观察线是否可交付 |
| SHRUN005 | 英语独立游客可用性测试 | 至少一名非中文母语者按路书走，记录迷路点、误解、疲劳与反馈 | 决定路书是否适合真实客人 |
| SHRUN006 | 英文太极体验 | 英语试教、场地/雨备、履历、人数价格、拍摄、交易、健康安全七项证据 | 七项全通过才可预订/收款 |

每次只做一个编号。每条记录至少提供两条可追溯证据，并填写“通过/有条件通过/不通过/信息不足”。没有证据不能把“看起来没问题”写为通过。
