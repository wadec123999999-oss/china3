# 上海英文路书｜外国游客可用性测试包 V1.0

目标：不是请对方夸路线，而是验证一位非中文母语的独立游客能否真的靠路书作出下一步决定。对应现场记录：`SHRUN005`。

## 招募条件

- 英语可沟通，非中文母语或首次/较少来中国的旅行者。
- 不需要是付费客户；建议 1 位首访 + 1 位有中国旅行经验者。
- 允许匿名记录其困惑点；不采集护照、联系方式、照片等不必要信息。

## 测试材料

- 交付一份与其日期/兴趣相符的英文路书样稿。
- 不附中文协助，不预先讲解路线。
- 对方只需模拟或实走一段 45–90 分钟路线。

## 任务

1. 用自己的话解释：“这条路线想让我理解什么？”
2. 找出第一个集合/起步点和备选方案。
3. 说出若下雨、太热或体力下降时应删掉什么。
4. 找出一条动态信息，并说明他/她会在哪里再次确认。
5. 说出哪些地方不该拍摄或进入。

## 通过门槛

只有当测试者能独立复述路线目的、指出至少一个动态复核点、理解住区/拍摄边界，且没有重大迷路或安全误解，`SHRUN005` 才可填 `pass`。任何一项失败，应填写 `conditional_pass` 或 `fail`，并先修改路书再复测。
