# A Deeper China｜独立站接口接入说明 V0.1

`src/site-api.mjs` 是网站前端和城市数据库运行时之间的无状态适配层。它可以直接包在 Vercel/Next.js 的 route handler 中；本文件不要求当前线上站点立即改动。

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/api/health` | 检查服务是否在线 |
| `GET` | `/api/destinations` | 获取可公开展示的城市单元、主题、最少夜数和产品等级 |
| `POST` | `/api/route-direction` | 将客户原话转成路线方向、隐性需求假设和下一问 |
| `POST` | `/api/runtime-input` | 将结构化客户 intake 转成城市运行时输入 |
| `POST` | `/api/dispatch-runtime` | 执行城市数据库运行时，返回按天草稿、客户可读 `roadbook_markdown`、结构化 `public_roadbook`、模块、点位 ID、追问和警告 |
| `POST` | `/api/roadbook-brief` | 创建带人工复核闸门的路书 brief |

## 关键边界

- 接口不返回原始数据库、内部来源记录、候选供应商或隐私字段。
- 接口只生成 `research_draft` / `day_sequence_draft`，不会自动标记 `human_checked_ready`。
- `roadbook_markdown` 是客户可读的研究草稿，不是已核验成品；网站必须同时显示当前状态和复核边界。
- `public_roadbook` 是给网站组件使用的结构化客户模型，包含路线主旨、客户上下文、每日模块、路线控制、备用逻辑和核验清单；它不包含内部模块 ID、来源评分或供应商字段。
- `route_controls` 是网站显示“为什么这不是普通景点清单”的核心字段：`one_question_per_day`、`stop_when_answered`、`protect_recovery_time` 和解释文字。
- 每个公开模块包含 `anchor`、`what_to_notice`、`stop_rule`、`main_friction`。这些字段用于卡片式路书，不应被前端隐藏在内部日志中。
- 结构化输出合同见 `public-roadbook.schema.json`；网站应按该合同读取字段，不要依赖 Markdown 标题名称。
- 运行时 handoff 可携带清理后的 `trip_context`（日期、夜数、人数、节奏、住宿区域和输出语言），路书应显示这些客户已确认的条件；不得把原始聊天全文或不必要的个人信息带入公开输出。
- 接口不处理预订、支付、住宿、交通、导游、在地体验或第三方收款。
- 每份正式路书仍须用真实日期、当前证据和人工审核记录通过发布闸门。

## 网站接入方式

拿到独立站源码后，在网站的 server route 中调用：

```js
import { handleSiteApiRequest } from '../path-to-router/src/site-api.mjs';

export async function GET(request) {
  return handleSiteApiRequest(request);
}

export async function POST(request) {
  return handleSiteApiRequest(request);
}
```

前端只需要调用同源 `/api/...`，不应把数据库 JSON、来源评分或内部人工审核字段打包进浏览器。

## `dispatch-runtime` 返回示例

```json
{
  "valid": true,
  "runtime": "shanghai",
  "output_capability": "day_sequence_draft",
  "day_sequence_available": true,
  "days": [{"day": 1, "theme": "...", "module_ids": ["SHM01"]}],
  "roadbook_markdown": "# A Deeper China | Shanghai draft\n...",
  "public_roadbook": {
    "route_controls": {
      "one_question_per_day": true,
      "stop_when_answered": true,
      "protect_recovery_time": true,
      "explanation": "The route gets shorter when the guest has understood the idea; more stops are not automatically better."
    },
    "days": [{
      "day": 1,
      "theme": "...",
      "modules": [{
        "name": "...",
        "question": "...",
        "anchor": "...",
        "what_to_notice": "...",
        "stop_rule": "...",
        "main_friction": "..."
      }]
    }]
  },
  "warnings": ["Dynamic details need a dated human check before delivery."],
  "delivery_rule": "This output may be used as a tailored draft only."
}
```

网站显示时建议把 `roadbook_markdown` 渲染为只读内容，并在标题附近显示：

> Research roadbook draft — current checks still required

客户版路书可显示如下清理后的简报上下文：

```text
Trip brief used for this draft
- Dates: 2026-09-10 → 2026-09-13 (3 nights)
- Travelers: 2 travelers
- Pace: slow
- Overnight area: to confirm
- Output language: English
```

只有发布闸门返回 `human_checked_ready`，才可换成 Human-checked digital roadbook。
