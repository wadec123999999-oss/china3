# 泉州—德化体验资源放行卡 V1.0

每个资源一张卡。未完整填写即为 research_only，智能体只能记录兴趣。

| 字段 | 必填内容 |
|---|---|
| resource_id | 不可复用编号 |
| 类型 | 陶瓷、南音、茶、餐饮、街区、其他 |
| 公开主体 | 可公开的个人/机构名称与联系方式 |
| 英文能力 | 自主英文、需翻译、无英文 |
| 可公开资历 | 师承、经历、作品/机构介绍及授权 |
| 场地 | 地址、室内外、雨天、无障碍、卫生与消防 |
| 接待 | 时长、人数上限、年龄/身体限制 |
| 安全 | 风险、告知、责任、保险/急救说明 |
| 商业 | 价格、付款、取消、发票/收据、禁止隐性加价 |
| 拍摄 | 是否可拍人、过程、作品；是否可海外宣传 |
| 试访 | 首次无付费试访日期、问题、改进、复验 |
| 客户反馈 | 至少三份目标客群可公开使用的反馈 |
| 放行状态 | research_only / pilot_only / partner_ready |

## 放行条件

partner_ready 必须同时满足：英文或明确翻译方案、场地和安全检查、价格取消书面确认、拍摄授权、试访记录、目标客反馈、合同/合规审查。数据库本身不授予该状态。
