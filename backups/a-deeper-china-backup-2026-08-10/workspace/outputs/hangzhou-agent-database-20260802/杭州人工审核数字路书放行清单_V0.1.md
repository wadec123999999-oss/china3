# 杭州人工审核数字路书放行清单 V0.1

1. 确认从上海还是杭州机场/车站抵达；当天往返或过夜必须先决定。
2. 当天往返只能一个主锚点：西湖、龙井或灵隐。客户想要两项以上时，建议过夜。
3. 按客户日期复核车次、站点、预约、票务、天气、人群和末段交通。
4. 茶需求要区分：看茶园、学习、买茶、参与体验；不承诺任何茶品质或活动。
5. 灵隐等宗教空间核对进入、步行、台阶、礼仪、拍摄与天气替代。
6. 西湖、湿地、茶山的路线均要有雨热/疲劳恢复块。
7. 杭州与苏州做意图选择，不把两城默认打包。
8. 不含代订、接送、导游、打包门票住宿或第三方体验售卖承诺。
