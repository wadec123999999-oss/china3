# 广州人工审核数字路书放行清单 V0.1

1. 确认抵达/离开、酒店区域、移动数据、支付和可用满天数。
2. 按客户日期复核陈家祠、宗教空间、珠江当代区及任何票务项目的实际开放与实名要求。
3. 确认湿热、下雨、步行、儿童/长者和室内恢复要求。
4. 收集饮食限制、辣度、拼桌/共锅、排队与用餐时间；不承诺特定餐厅。
5. 市场/批发类客户须确认身份、语言和观察目的，不承诺采购、价格或进入资格。
6. 晚间路线须核对实际返程与天气，不能按旧内容承诺夜景或船班。
7. 广州—深圳或广州—桂林只作为城市衔接建议，分别进入独立路书。
8. 文案不得含代订、接送、导游、打包门票住宿或第三方体验售卖承诺。

| 状态 | 含义 |
|---|---|
| draft | 数据库草稿，不能作运营性承诺 |
| human_checked | 按客户日期复核完成，可交付数字路书 |
| field_verified | 有现场运行记录，可形成稳定模板 |
| partner_ready | 需要独立合规、合同与供应商放行证据 |
