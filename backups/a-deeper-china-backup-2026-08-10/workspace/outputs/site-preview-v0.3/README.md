# A Deeper China — V0.3 living editorial preview

This is a separate, non-deployed interaction prototype. V0.1 and V0.2 are
preserved, and the live Next.js site is untouched.

## What is different

- Full-viewport cinematic hero with a live city switcher.
- Sticky navigation that changes state while scrolling.
- City chapters that crossfade image, copy and route signal.
- An SVG route line that draws as the route section enters the viewport.
- A roadbook spread that opens in place instead of appearing as a generic card.
- Real interaction states, reduced-motion fallback and mobile layout.
