## 执行顺序

### 上海

1. `SH-FIELD-001`：人民广场博物馆与市民核心区——先验证外籍游客入口、预约、证件、英文指引和雨天出口。
2. `SH-FIELD-002`：外滩—过江—浦东——验证一条完整低摩擦路线，不承诺具体游船、日落或机位。
3. `SH-FIELD-003`：衡复街区——验证连续步行、遮阴、厕所、休息和居民边界。
4. `SH-FIELD-004`：杨浦/滨水更新——验证工业遗存、步道连续性、夜间照明和缩短路线。

### 重庆

1. `CQ-FIELD-001`：解放碑—魁星楼—洪崖洞外观—大剧院江岸——验证高差、夜间拥挤和安全退出。
2. `CQ-FIELD-002`：朝天门江岸——验证两江方向、遮阴、座椅、雨热替代和回程。
3. `CQ-FIELD-003`：湖广会馆—东水门——验证外籍游客预约、证件、开放和英文支持。
4. `CQ-FIELD-004`：李子坝轨道—外部观察——验证乘车方向、站台、施工/出口变化和低体力版本。

## 每条任务都必须记录

- 实际日期、开始/结束时间、天气和人流；
- 入口、路线、转移、楼梯、遮阴、厕所、座椅和安全退出；
- 至少两条可追溯证据；
- 对客户旅行首日的适用日期；
- 具体 finding：什么成立、什么不成立、哪些说法必须删除；
- 结果只能是 `incomplete`、`pass`、`conditional_pass` 或 `fail`。

只有真实 `pass` 记录才能转换为 release evidence：

```bash

```

`incomplete`、`conditional_pass`、`fail` 或缺少真实 HTTPS 证据的记录，一律不能进入 release gate。
