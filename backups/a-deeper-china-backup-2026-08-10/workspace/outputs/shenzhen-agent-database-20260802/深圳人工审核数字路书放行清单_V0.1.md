# 深圳人工审核数字路书放行清单 V0.1

1. 明确客户的技术意图：观察、消费电子、硬件、设计、城市化、商务还是采购。
2. 若涉及工厂、企业园区、供应商、会议或采购，明确拒绝将其作为旅游路书交付，另行定义合法商务范围。
3. 华强北须按客户购买/观察目的复核路线、市场现况、支付、摄影礼仪与离开方案；不背书商品。
4. 展厅、科学馆、设计活动、OCT 等须按客户日期核验真实公共开放、节目、语言和票务。
5. 深圳湾、南头等路线仅使用公共空间，明确步行、天气和公共/私密边界。
6. 复核外卡、网络、地铁和末日机场行李/时间安排。
7. 广州衔接使用两城独立路书；香港衔接必须由客户护照/签证与官方当前信息决定。
8. 文案不得含工厂进入、采购结果、商品保证、代订、接送、导游、打包或体验报价承诺。

| 状态 | 含义 |
|---|---|
| draft | 数据库草稿，不能向客户作运营承诺 |
| human_checked | 动态信息已按客户日期复核，可交付数字路书 |
| field_verified | 有现场运行记录，可形成稳定模板 |
| partner_ready | 需要独立合规、合同与供应商证据 |
