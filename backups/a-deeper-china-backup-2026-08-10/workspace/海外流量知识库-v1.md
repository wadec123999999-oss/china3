# 海外流量知识库 V1

> 版本：2026-08-09  
> 范围：面向中国品牌、外贸工厂、跨境电商和创始人 IP 的海外获客。  
> 资料边界：只综合公开课程大纲、官方学习中心和公开案例；不复制或转述付费课的受版权保护内容。

## 0. 先用这份库的结论

海外流量不是“把抖音搬到 TikTok”。可复用的是一条增长链路：

`目标客户与市场 → 本地化内容 → 平台分发/付费放大 → 官网、店铺或线索表单 → 邮件/CRM/达人复投 → 复购与再营销`

国内课程可以贡献“定位、选题、内容生产、直播表达和产品设计”；海外平台的规则、广告、归因、店铺资格和达人合作机制，应以各平台官方材料为准。

## 2. 五个模块：把课程变成可执行能力

### 模块 A：市场与定位

**要解决的问题**：先做哪个国家、给谁卖、对方为什么从你而不是本地品牌购买。

每个市场只写一张《市场—客户—承诺卡》：

| 字段 | 必填答案 |
|---|---|
| 市场 | 只选一个首发国家/地区，而不是“欧美” |
| ICP | 行业、职位或消费场景、预算、现有替代品 |
| 强痛点 | 购买前最在意的一个风险/麻烦/收益 |
| 可证明的能力 | 产品测试、工厂、交期、认证、客户结果、创始人经验之一 |
| 一句话承诺 | “帮助【谁】在【场景】用【方式】获得【可验证结果】” |
| 转化动作 | 下单、索样、询盘、预约 Demo、下载资料，五选一 |

**原则**：内容可以面向广泛人群，但首个转化动作必须单一。B2B 不追求“爆一条视频”，而要让合适的人愿意留下工作邮箱或预约；DTC 则要让用户能迅速完成购买或进入达人联盟链路。

### 模块 B：内容生产与自然分发

所有平台共用一个内容内核，再按原生形式重做包装；不要机械一条视频全平台搬运。

| 内容支柱 | 解决的信任问题 | DTC 示例 | 工厂/B2B 示例 | 创始人 IP 示例 |
|---|---|---|---|---|
| 证明 | 你是否真的可靠？ | 测试、对比、真实使用 | 产线、质检、材料、交期案例 | 客户前后对比、实操复盘 |
| 教育 | 为什么需要这类方案？ | 避坑、选购、使用技巧 | 工艺/采购/认证知识 | 行业观点、决策框架 |
| 观点/人格 | 为什么关注你而不是同类？ | 品牌态度、使用场景 | 创始人专业判断 | 明确立场、个人故事 |
| 转化 | 下一步该做什么？ | 套装、评价、优惠、达人码 | 索样、规格表、询价、会议 | 邮件订阅、公开课、诊断 |

**一条内容的简报模板**：

```text
目标客户：
平台与国家：
视频前 2 秒要让他看到的冲突/结果：
一个证明：
一个观点或实用结论：
唯一行动号召：
本地化检查：语言、单位、价格货币、场景、敏感词、字幕、版权素材。
```

平台角色应分工：

- **TikTok / Instagram Reels**：高频发现、UGC、产品演示和测试素材。
- **YouTube Shorts**：触达新用户；**长视频/播客**：搜索、解释、对比和信任沉淀。YouTube 官方将 Shorts、长视频、直播、播客、增长和多种变现拆为独立学习模块，适合用作内容资产主站。
- **LinkedIn**：面向职业人群的观点、案例、白皮书和销售线索；官方材料明确把行业、职能、职位等职业信息定向和线索收集作为 B2B 场景能力。

### 模块 C：广告与放大

付费不是“视频没流量就加钱”，而是放大已经被验证的内容与转化路径。

标准顺序：

1. 先确定一个业务目标：销售、合格线索、网站转化或内容测试；不要混写“涨粉+曝光+成交”。
2. 用自然内容或小预算测试 3–5 个不同角度，而不是只改封面和字幕。
3. 看完整漏斗：观看/点击只是上游，继续看到站、表单有效率、下单、毛利和复购。
4. 只有当落地页、结账或销售跟进能承接时，才扩大预算。
5. 在广告平台回传合法、必要的数据，并遵循数据与隐私要求。

TikTok Academy 公开列出的学习范围是创意、广告、衡量、广告政策和行业内容；Meta Blueprint 公开课程覆盖广告目标、受众、Reels、线索、优化及数据/隐私。因此，广告账户、像素、事件、素材审核和归因必须以这两套官方学习中心的最新页面为准。

### 模块 D：达人与 UGC

达人不是一次性“买曝光”，而是一条内容生产、信任背书和可复投素材的供应链。

最小工作流：

1. 写清目标：曝光、可用 UGC、联盟成交或 B2B 专家背书，只选主目标。
2. 按“受众匹配度、内容质量、历史互动质量、商业合作自然度、交付可靠性”筛选，而不是按粉丝数排序。
3. 先小批量测试，再扩大；每位达人用独立链接、折扣码或追踪参数。
4. 合同写明：交付物、发布时间、审核范围、广告授权期限、二次剪辑权、披露义务、数据回传和取消条款。
5. 同时记录内容表现和商业表现；复投给“内容有效且人群正确”的创作者。

奇赞的公开红人营销资料可用来完善流程与指标；平台内的创作者合作、广告授权及披露规则则必须以目标平台和目标国家规则为准。

### 模块 E：承接、归因与复购

不要把粉丝当作资产；能继续触达且得到授权的数据才是资产。

| 业务类型 | 首选承接 | 关键后续动作 | 北极星指标 |
|---|---|---|---|
| DTC / 跨境电商 | TikTok Shop（有资格时）或独立站 | 邮件/SMS、评价、复购、达人联盟 | 贡献毛利，而非单纯 GMV |
| B2B / 工厂 | 询盘页、规格书下载、预约会议 | CRM 分级、48 小时内跟进、案例邮件 | 合格商机数与商机金额 |
| 创始人 IP / 咨询 | 邮件订阅、诊断申请、公开课 | 内容培育、预约、产品阶梯 | 有效线索到成交率 |

LinkedIn 的公开材料给出的 B2B 路径是：按目标选择品牌或线索形式，用案例/白皮书等内容收集线索，再以官网流量做再营销。这个“内容资产 → 留资 → 销售跟进 → 再营销”框架可跨平台复用。

## 3. 行业打法：先选一条，而不是全都做

### 路线 1：DTC 品牌/跨境电商

`产品演示与 UGC → TikTok / Reels → 店铺或独立站 → 达人联盟与复购`

第一阶段只验证：一个目标国家、一个核心产品、三个卖点、两类创作者。TikTok Shop 的具体资格、收款、履约和联盟能力按市场存在差异，操作前在相应市场的 Shop Academy 或卖家后台确认。

### 路线 2：外贸工厂/B2B

`工厂能力内容 → TikTok / YouTube / LinkedIn → 规格书或询盘 → CRM 跟进 → 再营销`

内容重点不是“我们工厂很大”，而是让采购看见：材料、工艺、质检、认证、交期、定制能力和真实应用。TK 增长会的公开大纲对“按行业拍工厂内容、用视频数据优化询盘”有参考价值；账号和平台操作细节需以官方规则替换。

### 路线 3：创始人 IP/知识/咨询

`短观点/案例 → YouTube 或 LinkedIn 的深度内容 → 邮件名单/公开课 → 咨询或产品`

不要一开始就复制国内直播逼单。先连续产出可验证的行业观点和案例，再把高意向用户导入可控的邮件、预约或活动页面。

## 4. 每周经营看板

每周只复盘下列六组数字，并在同一张表记录“内容主题—平台—国家—CTA”。

| 层级 | 要看什么 | 典型错误 |
|---|---|---|
| 内容 | 前段留存、完播、分享、评论质量 | 只看播放量 |
| 账户 | 主页访问、关注转化、受众国家/语言 | 把不相关国家的播放当成功 |
| 点击 | 链接点击率、到站率 | 不装追踪就投放 |
| 转化 | 下单、表单完成、预约、有效线索率 | 把垃圾表单算线索 |
| 经济性 | 获客成本、客单、毛利、退款、复购 | 只报 GMV 或 ROAS |
| 销售跟进 | 首次响应时间、商机率、成交周期 | 营销和销售各管一段 |

**每周动作**：保留 20% 最有效内容角度；停掉无法带来正确受众或转化信号的内容；把表现最好的内容交给广告和达人合作继续测试。

## 5. 30 天起步计划

### 第 1 周：定市场与基础设施

- 填完一张《市场—客户—承诺卡》。 
- 选一条业务路线和一个核心 CTA。
- 建好官网/店铺/线索页、隐私说明、基础追踪和 CRM 表格。
- 学 TikTok Academy 或 Meta Blueprint 的“广告目标、政策、衡量”基础模块。

### 第 2 周：内容资产与竞争研究

- 拆 20 个目标市场的同行或创作者：钩子、证明、评论中的购买疑问、CTA。
- 为四个内容支柱各写 5 条脚本，共 20 条。
- 每条只服务一个受众和一个 CTA；完成本地化检查。

### 第 3 周：发布与小测试

- 连续发布，记录每条的国家、语言、形式、钩子与结果。
- 选出 3 条“正确受众有明显反馈”的内容，做小预算放大或找小批达人测试。
- B2B 同步发布一个下载资料或案例页；DTC 同步准备商品页、评价与达人码。

### 第 4 周：复盘与建立第二轮假设

- 按经营看板归因：是内容、点击、页面、报价还是跟进出了问题？
- 只加码一条已验证的内容—转化组合。
- 形成下个月的内容主题、达人名单、预算上限和负责人的一页计划。

## 6. 学习顺序（避免买课后不落地）

1. **官方规则与测量**：TikTok Academy / Meta Blueprint / YouTube for Creators / 对应市场的 TikTok Shop Academy。
2. **全局框架**：三节课与中国传媒大学 MOOC，用来补平台选择、品牌、跨文化和本地化。
3. **业务专项**：B2B 看 LinkedIn 与工厂内容；DTC 看 TikTok Shop、Meta、达人/UGC；创始人 IP 看 YouTube 长短视频联动。
4. **购买陪跑前的尽调**：索要最近 30 天案例、讲师自己操盘的可验证账号/店铺、课程更新日期、适用国家、交付物、退款和合规边界。拿不到这些信息，不买。

## 7. V1 的边界与下一轮补齐项

- 这不是“平台秘籍”集合；平台产品、资格和政策变化快，操作时必须回到官方中心复核。
- 本版本尚未选择你的目标国家、产品和商业模式，所以提供的是决策与执行骨架，而不是具体脚本或预算。
- 下一轮应针对一个赛道建立：20 个当地对标账号、100 条内容钩子库、30 位创作者候选、一个落地页和一个周度数据表。

## 8. 入境中国旅游：独立站专用路线

### 8.1 业务定义

你的场景应按 **Inbound China Travel Lead Generation** 设计，而不是按跨境电商或泛流量课程设计：

`海外游客产生旅行问题 → Google/YouTube/Instagram/TikTok 搜索或刷到内容 → 进入独立站 → 获取行程/报价/预约 → 邮件或 WhatsApp 跟进 → 预订与评价`

### 8.2 优先渠道

| 渠道 | 作用 | 适合内容 | 首要 CTA |
|---|---|---|---|
| Google SEO / Search Ads | 捕捉已经想来中国、正在查路线的人 | 签证与入境准备、城市攻略、交通、费用、季节、行程比较 | Get itinerary / Request a quote |
| YouTube | 建立信任和搜索资产 | 城市实拍、路线拆解、避坑、真实预算、文化解释 | 下载行程 / 预约咨询 |
| Instagram Reels | 视觉种草与达人合作 | 风景、街区、美食、酒店、短路线 | View itinerary |
| TikTok | 快速测试话题和短视频钩子 | “第一次来中国”问题、交通演示、反差体验、误区纠正 | Visit the guide / plan your trip |
| Reddit / 社群 | 发现真实问题和语言表达 | 回答具体问题、引用自己的公开攻略 | 只在有价值时自然引用网站 |

Google 的 SEO 入门指南适合建立网站基础；Google Ads 和 GA4 官方学习中心适合搜索广告、事件和转化测量。YouTube、Meta、TikTok 的官方课程用于内容分发和付费放大。这里的课程组合比 TikTok Shop 或直播带货课程更贴近你的业务。

### 8.3 独立站最小可用结构

首页不要只写“欢迎来中国”，要让游客在 10 秒内知道你帮谁、去哪、怎么安排和为什么可信。

```text
/                         首页：目的地、客群、承诺、真实证明、CTA
/destinations/            北京、上海、西安、成都、张家界等目的地页
/itineraries/             3/5/7/10/14 天可购买或可定制路线
/experiences/             美食、摄影、文化、亲子、商务延伸体验
/china-travel-guide/      签证、支付、网络、火车、语言、季节、预算
/about/                   你是谁、当地资源、资质、服务边界
/reviews/                 真实评价、照片、来源、日期
/contact/                 表单、邮箱、WhatsApp/其他合规联系方式
```

每个目的地或路线页至少回答：适合谁、几天、预算区间、交通方式、包含/不包含、天气与体力要求、取消规则、支付方式、遇到问题如何联系。内容页要把读者自然带到对应路线页，不要只追求博客访问量。

### 8.4 内容支柱

1. **第一次来中国**：支付、网络、火车/高铁、城市间交通、语言和常见误区。
2. **路线决策**：北京和上海怎么选、7 天怎么排、亲子/摄影/美食路线怎么改。
3. **真实体验**：街区、餐馆、酒店、季节、排队、预算和“镜头外”的细节。
4. **文化解释**：把游客看到但不理解的习惯、历史和礼仪讲清楚，避免猎奇化。
5. **产品证明**：路线前后对比、客户评价、现场服务、突发问题如何处理。

每条视频只推一个 CTA：下载某城市行程、填写个性化规划表，或预约 15 分钟咨询。建议用英语作为第一语言；只有当某个国家持续产生有效线索时，再增加德语、西语、法语等版本，不要一开始铺十种语言。

### 8.5 课程购买顺序

对于这个业务，课程优先级应改为：

| 顺序 | 学习内容 | 目的 |
|---|---|---|
| 1 | Google SEO Starter Guide、Google Ads、GA4 | 让独立站可被找到、可测量、可优化 |
| 2 | YouTube for Creators | 建立城市攻略、路线解释和长期搜索资产 |
| 3 | Meta Blueprint | Reels、Instagram 广告、线索和再营销 |
| 4 | TikTok Academy | 短视频钩子和付费测试，不做店铺带货 |
| 5 | 国内 IP/直播课程 | 只学习选题、人设、表达、故事和转化话术 |

因此，现阶段不建议你下载 TikTok Shop、外贸工厂或直播成交类课程；除非你的独立站之后要卖可直接购买的旅游商品、导游团或体验套餐。

### 8.6 90 天验证目标

**第 1–30 天：**选择一个主国家和 2–3 个核心城市；上线英文首页、一个路线页、一个实用攻略页和一个行程申请表；发布 20 条短视频、4 条长视频。

**第 31–60 天：**围绕搜索词和评论问题扩充 10 个攻略页；测试 3 个短视频角度；和 5–10 个小型旅行创作者做内容交换或有明确交付的合作；设置邮件/WhatsApp 跟进序列。

**第 61–90 天：**只放大带来有效规划申请的主题；用 Search Ads 验证高意向词；把最常见的问题整理成路线产品、FAQ 和自动邮件；开始积累第一批可核验评价。

### 8.7 看什么数据

不要把播放量当核心结果，先看：

`目标国家访问占比 → 路线页到达率 → 行程申请率 → 有效咨询率 → 预约/预订率 → 获客成本与毛利`

对你来说，100 个正确国家的访问和 5 个有效行程申请，通常比 10 万个没有出行意图的播放更有价值。
